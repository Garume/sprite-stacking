# かさね島

平らなドット絵を重ねてできた、小さな島。スクロールだけで島が回り、輪切りが下から離れてまた重なり、建物がひとつずつ建っていく1画面のサイトです。

https://www.garume.work/sprite-stacking/

## 動かしかた

ビルドは不要です。ES モジュールを使っているので、このフォルダをローカルサーバーで配信して開いてください。

```sh
python -m http.server 5173
# http://localhost:5173/
```

## しくみ

- 画面は固定で、`index.html` の 8つの `<section class="stop">` がスクロールの長さだけを作ります（長さは `css/site.css` の `.js .stop` の `height`）。スクロール位置から「いまどの停留所か、次までどれだけ進んだか」を出し、島の角度・輪切りの離れかた・建物の建ち具合を決めます（`js/main.js` の `STOPS` と `draw`）。
- はじめは島（地面と木）だけです。建物は、その停留所へ向かう区間で、下の輪切りから順に降りてきて建ちます。スクロールをもどすと、上の輪切りから順に消えます。
- 「しくみ」の停留所では、島（地面と木）の輪切りが下から順に離れ、次の区間で下から順に重なりなおします。地面の1枚と見る位置は動かさないので、離れた輪切りは上下へ画面の外まで伸びます。
- 島は 352 × 352 × 120 のマスに、素材の番号を置いて作ります（`js/scene/`）。絵のファイルはありません。
- 描画は Canvas の `drawImage` を使わず、ドット単位の画面へ自前で描きます（`js/engine/renderer.js`）。1ドットごとに面の向きと光から明るさを決めるので、島を回しても影の向きは変わりません。高い輪切りから描いて、隠れる部分は飛ばします。
- 島を置く場所と倍率は、絵の広がりを実際の形から測って決めます（`js/scene/index.js` の `extent`）。倍率は画面の1ピクセル刻みで、止まっているときは絵のどのドットも同じ大きさで出ます。
- 「しくみ」の場面の文章の下に、描きかたを見せるボタンが2つあります。「描く順番」は高い輪切りから順に描いていくようすを、「描く範囲」は重なると隠れて描かない部分（縞）を見せます。この場面を出ているあいだは、ふつうの表示にもどります。

```
index.html             文章と停留所
css/site.css           見た目、区間ごとのスクロールの長さ
js/main.js             スクロール → 島の動き、メニュー、フォーカス
js/engine/palette.js   素材の色（明暗4段）
js/engine/volume.js    マスの入れもの。bake() で輪切りの絵に切り分ける
js/engine/renderer.js  輪切りを重ねて描く
js/scene/materials.js  素材の一覧
js/scene/island.js     地面
js/scene/town.js       建物、木、街灯
js/scene/index.js      組み立て、雲、絵の広がりの計測
```

## 建物を足す

1. `js/scene/town.js` に `v.beginPart('名前')` と `v.stamp(...)` で形を書く。`stamp` の中は「正面から見て右 u・正面方向 f・高さ k」。色は `js/scene/materials.js` に足す。
2. `js/scene/index.js` の `buildScene` で呼ぶ。
3. `index.html` に `<section class="stop" id="名前">` を足す。見出しには `tabindex="-1"` を付ける（場面が替わったときにフォーカスを移す先）。中の `<p class="dims" data-dims="名前">` に、枚数とドット数が自動で入ります。ひとつ前の場面の「次へ」ボタンの `href` も、新しい場面に向けなおす。
4. `index.html` の上のメニュー（`<ul id="places">`）に `<li><a href="#名前">` を足す。
5. `js/main.js` の `STOPS` に、角度と `focus: '名前'`、`build: [['名前', 0.15, 0.9]]` を足す。角度は「90 − 建物の方位」で、その建物が手前に来ます。`build` の2つの数は、ひとつ前の停留所からの区間のどこからどこまでで建つかです。「n / 8」の 8 は `STOPS` の数から入ります。

はじめから島にあるもの（木や岩）は、`v.beginPart('名前', { base: true })` で置きます。`build` に書かなければ、いつでも出ています。
